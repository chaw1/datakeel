# Generated automatic-routing fixtures

These six images are generated by `scripts/generate_auto_image_cases.py` using
Pillow's bundled default font. They contain only invented English examples.
Three are ordinary text pages. The remaining three preserve, respectively,
an arrow connecting an organisation diagram, a struck-through cancelled row,
and a grey cancelled row.

`expected_route` labels are independently authored. The transcriptions and
extractions in `auto-transcription.yaml` and `auto-extraction.yaml` are scripted
fixtures, not measurements of an OCR engine or a visual model. The script keeps
flattened OCR and visually interpreted text separate to exercise the production
route and extraction pipeline offline. It never uses labels to select a route.

Replay reports distinguish the selected VLM fraction from actual external
transfers, which are zero during replay. The existing 60-image benchmark and its
original recordings remain unchanged.

# 一句话做事

[English](ONE_SENTENCE.md)

在智能体对话里直接说要做什么，例如「给这批路口图建红绿灯框标注，两人交叉、抽 10%」。Datakeel 把这句话拆成一串已有的受控动作，列出每一步做什么、改多少、花多少、要不要签字；在你确认之前什么都不执行。像「这周谁的返工率最高」这样的问题，直接用读函数回答。

## 怎么理解一句话

1. **先走规则。** 几个固定说法（建标注项目、把某人没动的任务收回分给别人、起草标签集）和简单的查询问题，不用模型就能识别。
2. **再调一次模型。** 规则认不出时，用会话所配的模型调用一次，有上限。提示词里有登记表（每个动作和读函数的中英文说法）、可能用到的动作参数表、能看到的对象（人、项目、数据集、版本、标签集）和页面上下文。模型必须返回一个 JSON 对象，否则丢弃。
3. **严格检查。** 每一步必须是登记过的动作、参数合法。名字到目录里去对：对上一个就用，对上多个让人选，一个都没有就问。写操作用到的项目、任务包、数据集、标签集，必须来自当前页面、上一轮、前面的步骤或者这句话本身；模型从目录里抄来的值会变回提问。只有读操作才会在只有一个项目时默认用它。

参数来源：这句话本身、页面上下文（对话会带上数据集、版本、项目、任务包、任务、标签集和选中的对象）、上一轮涉及的对象。缺必填参数就问，候选对象可以一键点选。没有权限的请求在规划时就拒绝，并说出缺哪个权限（例如 `production:manage`），和手动做同一个动作时一样。

Web 智能体对话每条消息都会进入规划（它总是带页面上下文）。HTTP 发消息接口只有带 `context` 时才进入，老的客户端行为不变。

## 动作链、确认和续跑

计划存成一条动作链，每一步都是普通的受控动作；`{"$ref": "s1.label_set_id"}` 表示用前面某一步回执里的值，一步可以对多个对象分别执行。

- **确认**：人点「确认执行」（或命令行 `datakeel intents run <chain>`；HTTP `POST /api/intents/chains/{id}/run`）。每一步按顺序准备和执行，走的是和手动操作相同的服务，所以回执、审计、血缘完全一样，署名是本人。
- **签字**：不可逆、外发或受治理的步骤进审批队列等签字。可以直接在动作链卡片里签，也可以去审批页签，签完动作链继续。
- **失败**：停在失败的那一步并写明原因，已完成的步骤保留。点「续跑」（或同样的命令行/HTTP 调用）会跳过已经执行过的步骤和对象，绝不重做。签批被退回也算这一步失败；续跑会重新生成一张签批单等人签。
- 只有提出请求的人能查看和执行这条动作链。MCP 和智能体永远不能确认或执行写操作：MCP 没有动作链工具，智能体只负责提议。

命令行 `datakeel intents plan "<一句话>" [--dataset --version --project --package --actor]` 可以直接规划，`datakeel intents show <chain>` 查看。

## 说法登记（每个动作都必须有）

一句话入口只读动作登记表。每个动作和读函数都必须登记中文、英文说法，以及至少两条例句（中文、英文各一条）。缺任何一项，门禁测试 `tests/intents/test_language_gate.py` 就会失败。新动作在 `datakeel/actions/action_language.py`（`ACTION_LANGUAGE`）或 `datakeel/actions/production_language.py`（`PRODUCTION_LANGUAGE`）里加一个四元组：`(中文说法, 英文说法, 中文例句, 英文例句)`。读函数在 `datakeel/ontology/function_language.py` 里登记。

## 起草标签集和标注指南

`draft_label_set` 是受控动作（「按这批图起草一份车辆标签和标注指南」）。它需要签字，签字前什么都不写。它读取：

- **数据标准**：字段的代码表变成标签树，其他标准字段变成标签属性；
- **已有标注**：数据集已有标注批次里的类别，以及以前的标签集；
- **抽样文件**：数据集版本里最多 50 个文件。

结果是一个新的**未发布**标签集版本：中英文名、属性、总说明和每个标签的指南，带正例和反例。例子引用的都是真实样本 ID，模型编造的 ID 会被丢掉并计数。这个版本记录了来源（数据标准、标签集、数据集、样本、模型、token、费用、计划编号）。在动作链卡片里可以改名字和指南，点「保存修改」（生成一张 `create_label_set` 更新计划），再点「发布…」走普通的 `publish_label_set` 签批单。

模式：`offline`（默认，确定性，不花钱）；`cloud-text`（`deepseek-flash`，密钥放 `DATAKEEL_DRAFT_TEXT_API_KEY`）；`cloud-vision`（百炼上的 `qwen3.5-flash`，会带缩略图，密钥放 `DATAKEEL_DRAFT_VISION_API_KEY`）。云端起草在签批单上显示预估费用；签批的 `max_cost_usd` 低于预估时拒绝执行。模型和地址可以用 `DATAKEEL_DRAFT_TEXT_MODEL`/`_BASE_URL`、`DATAKEEL_DRAFT_VISION_MODEL`/`_BASE_URL` 修改。

## 限制

- 不能按位置挑任务（「前两个任务」），入口会问是哪些任务。
- `rework_rate` 统计项目的全部审核记录，不按「这周」筛选，回答里会说明。
- 规划用的模型就是会话的模型；离线演示模型只用固定说法。

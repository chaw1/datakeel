# 问数图表与多轮追问

[English](ASK.md) · [导览](DEMO.md)

问数只使用已登记指标和只读查询。后端根据结果形状用确定性规则选图，不调用模型，前端不增加图表库。
图和表共享同一份结果行，单位和数字格式取自指标合同。

| 结果形状 | 默认展示 |
| --- | --- |
| 单个数值 | 单值卡片 |
| 时间序列 | 折线图 |
| 类别比较 | 纵向柱图 |
| 超过八类或标签过长 | 横向柱图 |
| 两个维度 | 分组柱 |
| 超过两个维度、超过三十类或没有数值列 | 表格 |

明确分组的占比问题用柱图加百分比：每行指标值除以「本次返回结果行中指标值的总和」。
原始指标值与等价分组问题的 SQL 保持一致；分母按本次筛选和返回行范围确定，不包含未返回的源数据行。
没有明确分组、否定占比或另加不支持的平均/比率计算时，先澄清或拒绝，不猜测分母。
返回指标值总和为 0 时，不计算占比百分比。

每张图提供可访问的标题和描述；Web 中可用键盘在自动选择的图型与原始表格之间切换，
暂不提供手动选择其他图型。浅色和深色主题沿用应用的字号和颜色变量。

## 在同一个会话里接着问

新建问数会话，参考日期保留演示值 `2026-10-01`，先问「上个季度各区域零售额是多少」，再问
「那华南呢」「按月拆开」「换成订单数」。也支持英文，例如 `what about South China`、
`by month`、`switch to order count`。解析器保留上一轮的指标、时间、筛选和分组，只修改追问指出的部分。
同比和环比复用同一指标引擎查询两期；上一期没有数据时说明缺失，不编造百分比。
完整的新问题会清空旧查询框架。

泛称「环比」或 `period over period` 时，比较当前区间与紧邻的上一相同区间。
明确指定「和上个月比」或 `MOM` 时，当前区间须是完整自然月；指定「和上个季度比」或 `QOQ` 时，
须是完整自然季度。指定的比较粒度与当前区间不匹配时，先澄清，不执行查询。

每一轮都显示「**理解为**：完整问句」，使用数字前可直接核对。模糊追问先澄清，不给数字。
会话列表可重新打开或删除历史；刷新页面和进程重启后都从 SQLite 或 PostgreSQL 恢复。
不同浏览器标签页分别保存当前选中的会话。
`DATAKEEL_ASK_CONVERSATION_RETENTION_DAYS` 配置会话保留天数。
默认 30 天，可设为 1–3650 天。过期记录在问数读取、列出会话或写入时清理；空闲期间没有后台擦除任务。

删除问数会话会清除其查询框架、问句与答案记录，并停止原答案和缓存 `ask_data` 工具结果的重放。
不可变的证据与血缘审计引用仍保留。已经进入独立智能体对话或工具审计的答复副本，仍随对应记录的
生命周期保留；删除问数会话不会擦除这些独立副本。

每一轮查询和历史读取都会重新检查当前资产授权；以前拿到答案不代表以后仍有权限。
授权撤销或过期后，重放答案和打开会话也会被拒绝。会话仅属于创建它的操作人。
问数 `conversation_id` 与智能体运行时的会话 ID、原有澄清用的 `session_id` 分开。

## CLI、HTTP、Agent 和 MCP

首条命令返回 JSON，包含 `conversation_id`、`interpreted_question` 和 `chart`。将返回的会话 ID
填入第二条命令即可接着追问：

```sh
uv run datakeel ask '上个季度华东区零售额是多少' --reference-instant 2026-10-01T00:00:00Z
uv run datakeel ask '那华南呢' --conversation-id YOUR_CONVERSATION_ID --reference-instant 2026-10-01T00:00:00Z
```

`POST /api/ask` 增加可选的 `conversation_id`，省略时新建问数会话。
返回仍是可重放的答案合同，增加图表和会话字段。

| HTTP | 用途 |
| --- | --- |
| `POST /api/ask/conversations` | 新建空会话，无需请求体 |
| `GET /api/ask/conversations` | 列出当前操作人可读取的会话 |
| `GET /api/ask/conversations/{id}` | 打开会话及历史轮次 |
| `DELETE /api/ask/conversations/{id}` | 删除问数会话及保存的答案重放 |
| `GET /api/ask/{answer_id}` | 重新检查当前授权后重放答案 |

管理会话和提问时保持 `X-Datakeel-Actor` 一致，HTTP 默认值是 `local-user`。
没有该请求头时，提问请求仍支持原有 `actor` 字段。
Agent 只读工具和 MCP 的 `ask_data` 复用同一请求 schema：后续调用传入上一轮返回的
`conversation_id`，它们固定使用操作人 `local`。问数会话不会增加写入或审批权限。
